A faster drop-in for csv-reader 1.0.0: an indexOf-driven CSV reader that
answers exactly as csv-reader does on every case — same records, same
`{columns, rows, errors}` — at a fraction of its CPU time. The reference
reads one character at a time; this one finds each field's end with
`indexOf` and takes whole runs with `slice`, with the same treatment for
quoted fields, doubled quotes, stray CRs, unterminated quotes and quote junk.

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```
